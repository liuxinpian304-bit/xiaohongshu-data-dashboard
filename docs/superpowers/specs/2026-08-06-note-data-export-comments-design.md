# 笔记数据总览、ZIP 导出与全部评论设计

## 目标

让运营人员进入笔记页后无需逐张卡片点开，即可比较每条笔记的关键数据；可一键导出当前账号筛选范围内的全部笔记和评论；进入笔记详情后自动加载并查看该笔记的全部评论与回复。

## 笔记列表

笔记页提供“表格”和“卡片”两种视图。默认使用表格视图，并在浏览器中记住用户最后一次选择。

表格每行展示：

- 笔记标题
- 所属账号
- 发布时间
- 访客
- 点赞
- 评论
- 收藏
- 数据来源
- 数据完整性状态
- 查看详情操作

卡片视图保留视觉封面，同时在卡片正文直接展示访客、点赞、评论、收藏和同步状态，不再只显示标题、时间与来源。

指标值必须沿用现有可用性语义：真实可用值正常显示；明确为零时显示 `0`；缺少快照或无法验证时显示“尚未同步”，禁止用零替代未知值。账号筛选同时作用于列表和导出范围。

## 一键导出

笔记页顶部提供醒目的“一键导出全部数据”按钮。按钮导出当前账号筛选范围内的全部笔记、全部评论和回复，而不是仅导出当前加载页。

导出结果为 ZIP，包含：

- `notes.csv`：笔记标识、标题、账号、发布时间、来源、访客、点赞、评论、收藏及各指标可用性。
- `comments.csv`：笔记标识、评论标识、父评论标识、作者、正文、发布时间、点赞数和回复层级。
- `README.txt`：导出时间、账号筛选、记录数量、数据来源及完整性说明。

小数据量同步下载；超过既有限额时沿用后台任务机制，页面显示任务编号并链接到任务页。CSV 使用 UTF-8 BOM，保证 Excel 直接打开中文不乱码。ZIP 文件名包含上海时区导出日期。

## 笔记详情指标

详情页顶部使用紧凑指标卡展示访客、点赞、评论和收藏。每张卡片同时显示值、数据时间和可用性说明。没有任何指标快照时展示明确的同步提示，不再保留大面积空白占位区域。

## 全部评论

详情页打开后自动按现有评论游标接口逐页加载，直到没有下一页。页面展示加载进度，例如“已加载 350 / 1200 条”；如果接口暂时无法提供总数，则展示“已加载 350 条，正在继续”。

全部评论加载完成后按评论树展示根评论和回复。大量评论使用虚拟化或分段渲染，避免一次渲染数千个 DOM 节点。用户不需要手动点击“加载更多”。

评论区展示：

- 评论正文
- 作者标识或昵称（数据提供时）
- 发布时间
- 点赞数
- 父子回复层级
- 当前评论数据完整性状态

详情页提供“导出本笔记评论”按钮，复用现有评论 CSV 导出能力。

## 评论缺失与同步状态

必须区分以下情况：

- 已完整同步且没有评论：显示“该笔记暂无评论”。
- 只完成部分分页：显示已加载数量和“不完整”提示。
- 尚未同步评论：显示“该笔记尚未同步评论”。
- 登录失效或授权不足：显示“需要重新登录小红书”。
- 抓取失败：显示失败状态和“立即同步评论”按钮。

“立即同步评论”调用现有本地采集器同步流程，不伪造评论，也不绕过小红书授权状态。同步进行中显示阶段与进度，完成后刷新评论。

## API 与数据边界

保留现有 connector 接口和 mock 演示。列表 API 增加笔记所属账号显示信息、最新指标投影和评论完整性状态；不改变 Note、MetricSnapshot 和 Comment 的权威存储模型。

ZIP 导出使用独立的认证 API/BFF 路由，服务端流式生成文件，临时文件使用受限权限并在响应完成后清理。导出必须应用账号权限和筛选条件，禁止通过客户端提交任意文件路径或未授权账号标识。

全部评论仍使用有界分页 API。前端自动翻页必须检测重复游标、设置最大安全页数，并在异常时停止且展示部分加载状态，防止无限循环。

## 视觉与交互

- 首屏优先显示关键数字，减少大封面占用。
- 表格在桌面端固定表头；移动端转换为紧凑数据卡，不产生页面级横向滚动。
- 表格/卡片切换使用可访问按钮组并标记当前状态。
- 导出按钮在加载期间禁用并显示进度或后台任务状态。
- 数据来源文案准确区分账号自抓、官方 API 和演示数据。

## 测试与验收

1. 默认表格一屏可看到多条笔记及四项核心指标。
2. 切换卡片后指标仍完整，刷新页面保持上次选择。
3. 账号筛选同时限制列表和 ZIP 内容。
4. ZIP 包含三个约定文件，中文可被 Excel 正常读取。
5. 导出不受当前页面 50 条分页限制。
6. 笔记详情自动读取所有评论分页，重复游标会停止并提示。
7. 评论为零、未同步、部分同步、授权失败和抓取失败有不同文案。
8. 大量评论不会造成页面明显卡顿。
9. 单笔记评论导出继续可用。
10. 现有 mock、官方 API 预留和 self-scrape 数据源保持兼容。

## 非目标

- 本阶段不修改小红书抓取策略或绕过登录授权。
- 不把未知指标补零。
- 不增加 Excel 专有 `.xlsx` 生成；ZIP 内使用 Excel 兼容 CSV。
- 不重构现有 connector 接口。
