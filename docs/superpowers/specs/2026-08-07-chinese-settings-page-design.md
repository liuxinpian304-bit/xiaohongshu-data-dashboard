# 中文系统设置页设计

## 目标

为左侧导航的“设置”入口提供真正可用的中文页面，替换当前不存在路由导致的英文 Next.js 404 页面。页面用于集中查看系统运行状态、账号登录状态、数据源能力和本地部署信息。

## 页面结构

### 页面标题

- 标题：系统设置
- 说明：查看数据驾驶舱的运行状态和数据连接配置。

### 运行状态

展示以下服务的中文状态：

- 网页服务
- API 数据服务
- 本地采集器
- 数据库

状态仅使用“运行正常”“连接异常”“尚未启用”，不直接暴露内部异常堆栈、令牌或连接密码。

### 账号与登录

- 展示当前本地采集器检测到的小红书账号昵称、小红书号和登录有效状态。
- 没有登录时显示明确的中文引导。
- 提供“前往账号管理”链接，不在设置页复制扫码、删除账号等账号操作。

### 数据源说明

分别说明三类数据源：

- 账号自抓数据：当前真实数据入口。
- 官方 API：保留入口，审批通过后启用。
- 演示数据：仅用于界面和流程演示。

### 系统信息

- 当前应用版本。
- 时区：Asia/Shanghai。
- 数据存储说明：本机数据库，不展示实际数据库密码或敏感文件路径。

## 数据与接口

- 网页服务状态由设置页成功渲染本身确定。
- API 状态通过受保护的健康状态接口读取。
- 采集器及登录状态复用现有 `/local-collector/status` 能力。
- 数据库状态由 API 健康检查返回，不允许网页直接连接数据库。
- 接口不可用时页面仍可渲染，其对应卡片显示“连接异常”。

## 交互与安全

- 页面全部使用中文文案。
- 页面为只读状态中心，仅提供安全的内部导航链接。
- 不展示管理员密码、Cookie、采集器令牌、数据库地址或凭据。
- 未登录管理员继续跳转到登录页，登录后返回 `/settings`。

## 验收标准

- 点击左下角“设置”后进入 `/settings`，不再出现英文 404。
- 页面标题、状态、说明和错误提示全部为中文。
- 服务正常时显示运行正常；接口异常时局部显示连接异常，页面不会整体崩溃。
- 当前小红书登录身份可在设置页查看，并能跳转到账号管理。
- 网页组件测试、类型检查和浏览器验收通过。
