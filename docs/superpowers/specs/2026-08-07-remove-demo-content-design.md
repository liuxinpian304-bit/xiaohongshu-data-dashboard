# 删除演示内容设计

## 目标

从账号驾驶舱中彻底移除可见、可创建和已存储的演示内容，只保留真实的 `self-scrape` 小红书账号及其业务数据，同时保留未来接入官方 API 的静态入口和代码扩展边界。

## 最终范围

- 删除账号页的“演示授权”按钮、演示二维码弹窗和“演示连接器”创建表单。
- 删除设置页、账号列表、笔记和指标区域中只用于演示的说明或操作入口。
- 后端拒绝通过账号授权接口创建 `mock` 或其他测试连接器账号，避免演示数据再次进入生产数据库。
- 清理数据库中所有非 `self-scrape` 账号及其关联业务数据。
- 保留真实账号“南瓜汤与瓜子仁”、小红书号 `95874286519`，以及它关联的笔记、指标快照、评论、回复、同步任务和报告数据。
- 保留官方 API 未配置提示及未来 `official` connector 的扩展位置，但数据库中不保留测试性质的 `official` 账号。
- 保持真实账号卡片的“立即同步”和“登录新账号”功能不变。

## 界面设计

账号页顶部继续展示已登录的真实账号卡片。每张卡片保留头像、昵称、小红书号、登录状态和独立同步按钮；最后一张卡片继续用于登录新账号。

账号页下方不再出现演示连接器、演示凭据、创建演示账号或演示授权。页面只保留两类说明：当前真实数据来自账号自抓，以及官方 API 审批通过后可接入。账号管理列表只渲染 `self-scrape` 真实账号；异常来源即使意外进入接口响应，也不在界面中伪装成真实账号。

设置页删除“演示数据”来源卡片。笔记列表、笔记详情和总览中的来源标签不再向用户展示“演示数据”或“演示连接器”。真实数据继续标记为“账号自抓数据”，官方来源继续标记为“官方 API”。

## 后端约束

生产账号授权入口不再接受 `mock`、测试后缀或任意未知连接器类型。当前官方 API 尚未配置，因此该入口对所有创建请求返回“连接器不可用”；真实 `self-scrape` 账号仍由本机扫码登录和同步流程创建或更新，不通过演示授权接口。

现有 connector 接口结构保持不变，以便未来获批后重新启用 `official` 授权。此次不重构 connector registry，也不改变自抓 JSON/本机采集链路。

## 数据清理与安全

清理前先执行只读盘点，按 `connectorType` 列出账号数量，并记录目标真实账号的账号 ID、笔记数、指标数、评论数、回复数、任务数和报告数。

随后在本机应用数据目录创建带时间戳的 PostgreSQL 完整备份。备份成功且文件非空后，才允许进入删除事务。

删除事务以 `connectorType <> 'self-scrape'` 为候选条件，并在执行前再次断言目标真实账号存在且小红书号为 `95874286519`。关联数据按外键安全顺序删除，或使用 schema 已定义的级联关系；共享的指标定义仅删除已经无任何真实快照或报告引用、且明确属于测试数据的记录。`views`、`likes`、`comments` 三条真实业务指标定义必须保留。

清理后再次执行同一组只读统计，必须满足：账号表只剩 `self-scrape`；真实账号 ID 不变；其笔记、指标、评论、回复、任务和报告数量与清理前一致。若任一断言失败，事务回滚并保留备份供恢复。

## 测试策略

- Web 组件测试先证明账号页不存在演示授权、演示连接器和创建演示账号入口，再修改组件使测试通过。
- API 单元测试先证明 `mock` 和未知连接器创建请求会被拒绝，再实现最小限制。
- 数据清理脚本提供默认 dry-run 和显式执行模式；对候选选择、真实账号保护条件及清理后断言进行测试。
- 数据库相关测试必须使用独立测试数据库，禁止连接当前运行中的 `xhs_dashboard` 生产数据库。
- 完成后运行受影响的 Web/API 测试、类型检查，并在浏览器中验证账号页、设置页、笔记列表和笔记详情。

## 发布与回滚

代码按独立步骤提交并推送到 `origin/main`。数据库清理作为单独步骤执行，执行前记录备份绝对路径。发布后重启固定服务并检查 Web、API、collector、PostgreSQL 和 Redis 健康状态。

如界面或接口回归，回退对应 Git 提交并重新部署；如数据库校验失败或误删，则立即停止同步服务并从本次清理前备份恢复，不使用猜测性补数据。

## 验收标准

1. 账号页、设置页、笔记相关页面不再出现任何演示按钮、表单、账号或演示来源说明。
2. 无法通过公开 BFF/API 创建 `mock` 或未知测试连接器账号。
3. 数据库中只存在真实 `self-scrape` 账号。
4. “南瓜汤与瓜子仁”及其所有既有真实业务数据在清理前后数量一致。
5. 官方 API 未配置入口仍然可见但不可误创建账号。
6. 真实账号同步、登录新账号、笔记查看、评论查看和导出功能不受影响。
